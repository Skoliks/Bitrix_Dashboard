# Дашборд воронки продаж для Bitrix24

Read-only приложение для аналитики сделок CRM Bitrix24.

## Что показывает

- количество и суммы сделок по стадиям воронки;
- общую сумму открытых сделок;
- количество выигранных сделок за выбранный период и средний чек;
- последние 15 сделок с названием, суммой, стадией и ответственным;
- динамику сделок и фильтр периода.

## Права

- `crm` — чтение сделок и стадий CRM;
- `user_brief` — отображение ответственных;
- `placement` — размещение приложения в интерфейсе Bitrix24.

Приложение не создаёт, не изменяет и не удаляет записи CRM.

## Структура

- `dashboard-app/` — Vue 3 frontend;
- `backend/` — Node.js BFF, который получает CRM-данные и отдаёт готовую аналитику;
- `scripts/` — проверки production-артефакта, секретов и лицензий.

## Ограничения

- Аналитика строится по выборке до 500 сделок; при большем объёме результат помечается как неполный.
- Инструкция развёртывания и подключения к конкретному порталу предоставляется отдельно: секреты в репозитории не хранятся.

## Локальная проверка

Требуются Node.js 20+ и pnpm 10+.

```powershell
cd backend
pnpm install --frozen-lockfile
pnpm run build:production
pnpm run test
pnpm run security:scan
```

Для frontend-проверок:

```powershell
cd dashboard-app
pnpm install --frozen-lockfile
pnpm run lint
pnpm run typecheck
pnpm run test
```
