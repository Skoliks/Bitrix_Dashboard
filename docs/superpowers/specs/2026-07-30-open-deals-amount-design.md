# Phase 15: Сумма открытых сделок — дизайн

## Цель

Дополнить существующий KPI «Открыто сейчас» денежными суммами открытых
сделок, чтобы выполнить требование клиентского ТЗ об общей сумме открытых
сделок.

## Границы

- Работа выполняется для локального owner-demo режима.
- Bitrix24 placement, iframe-приёмка и пользовательская OAuth/Gateway-сессия
  не входят в эту фазу.
- Пагинация не входит в эту фазу и будет спланирована отдельно.
- Новая KPI-карточка не создаётся: расширяется существующая «Открыто сейчас».

## Контракт данных

`DashboardResponse.kpi.openNow` расширяется с:

```ts
{ count: number }
```

до:

```ts
{
  count: number
  amountsByCurrency: Array<{ currency: string; amount: number }>
}
```

Суммы всегда передаются раздельно по валютам. Конвертация и объединение
валют запрещены.

## Правила расчёта

- Выбираются все открытые сделки выбранной воронки.
- Выбранный период не ограничивает этот KPI.
- Валютный фильтр применяется: `all` возвращает отдельные суммы каждой
  валюты, конкретный код валюты оставляет только соответствующую сумму.
- Сделка без суммы участвует с `amount = 0`.
- Сделка без валюты учитывается в `count`, но исключается из денежных сумм;
  применяется предупреждение `INCOMPLETE_FINANCIAL_DATA`.
- При ограниченном snapshot до 500 сделок сохраняется текущее предупреждение
  `PARTIAL_AGGREGATION`; фазу пагинации это не заменяет.

## Отображение

Карточка «Открыто сейчас» продолжает показывать количество сделок и ниже
выводит форматированный список сумм по валютам. При пустом списке сумм
карточка остаётся корректной и не подменяет отсутствие валютных данных нулевой
суммой в вымышленной валюте.

## Проверки

- Backend unit-тесты: несколько валют, одна выбранная валюта, отсутствие
  валюты, отсутствие суммы и независимость KPI от периода.
- Контрактные HTTP-тесты: расширенная DTO-форма и предупреждения.
- Frontend unit-тесты: форматирование и отображение валютных сумм, пустой
  список сумм.
- Полный набор существующих lint, typecheck, test и production build проверок
  для `backend/` и `dashboard-app/`.

## Критерии готовности

- API возвращает `openNow.count` и `openNow.amountsByCurrency`.
- UI отображает сумму открытых сделок рядом с их количеством.
- Валюты не объединяются и не конвертируются.
- Поведение для неполных данных и bounded snapshot явно предупреждает
  пользователя.
