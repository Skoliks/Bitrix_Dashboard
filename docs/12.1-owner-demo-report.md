## Runtime Profile

Only server-side deployment environment contains values for these names:

```env
NODE_ENV=production
VIBECODE_API_BASE_URL=https://vibecode.bitrix24.tech/v1
VIBECODE_API_KEY=<personal owner API key>
SESSION_CONTEXT_MODE=owner-api-key
OWNER_DEMO_PORTAL=<single allowed Bitrix24 portal domain>
```

The browser supplies no portal, Bitrix24 user, VibeCode key, or session token.
The backend validates that the server-side key belongs to the configured portal
before using read-only CRM endpoints.

## Rollback To Client Integration

```env
VIBECODE_API_BASE_URL=https://vibecode.bitrix24.tech/v1
VIBECODE_APP_KEY=<OAuth application key>
SESSION_CONTEXT_MODE=gateway-headers
```

Remove `VIBECODE_API_KEY` and `OWNER_DEMO_PORTAL` from that deploy profile.
Then confirm an unauthenticated dashboard API request returns `401
AUTH_REQUIRED` before enabling any Bitrix24 placement.
